## Introduction

Event Meeting 3 was a technical sharing session organized as part of the **AWS First Cloud AI Journey (FCAJ)** program. The event brought together engineers, AWS community members, and teams with practical experience in hackathons and cloud-based projects. The presentations focused on real-world implementation experiences, cloud-native architecture design, and valuable lessons learned throughout the software development process on AWS.

By attending this event, I had the opportunity to learn from practitioners who had worked on real projects, broaden my understanding of AWS architecture, and gain practical insights into building scalable and reliable cloud applications.

---

## Main Presentation Topics

### 1. Hackathon Journey - Team 3KA

The first presentation shared Team 3KA's experience participating in an AWS Hackathon, covering the entire development process from brainstorming ideas and assigning responsibilities to building a functional prototype and completing the project within a limited timeframe.

From this session, I realized that developing a successful product requires much more than programming skills. Effective teamwork, communication, time management, and the ability to make appropriate decisions under pressure are equally important throughout the project lifecycle.

---

### 2. OneTeam & AWS Community Day

The speakers introduced AWS community activities and highlighted the value of participating in AWS Community Day events. Beyond technical knowledge sharing, these communities provide opportunities for networking, collaboration, and continuous learning.

This presentation helped me understand that joining technology communities is an effective way to stay updated with new technologies, exchange experiences with others, and continuously improve both technical and professional skills.

---

### 3. SignalScout - Intelligent Signal Analysis on AWS

The SignalScout project demonstrated how AWS services can be integrated to build an intelligent signal analysis system powered by cloud technologies and AI.

Rather than focusing solely on algorithms, the presentation emphasized system architecture, workload distribution, and selecting appropriate AWS services for different processing requirements. This gave me a clearer understanding of how architectural decisions contribute to building scalable and maintainable AI applications.

---

### 4. Building Cloud-Native Applications with AWS Solutions Architecture

The final presentation focused on cloud-native application design based on AWS Solutions Architecture best practices.

The speakers discussed key principles such as **Scalability**, **High Availability**, **Fault Tolerance**, **Security**, and **Loose Coupling**, explaining how these concepts contribute to building reliable cloud applications. They also emphasized that choosing the right AWS services is more important than simply using many different services.

As my team was developing the **Fav Web Portal** project during the FCAJ program, I found this session particularly valuable because many of these architectural principles could be applied directly to our own project.

### 1. Better Understanding of Real-World Software Development

Through the hackathon presentations, I learned that building a complete product involves not only technical implementation but also effective collaboration, project planning, time management, and adaptability throughout the development process.

### 3. Broader Perspective on AI Applications on AWS

The SignalScout project provided practical examples of how AI and AWS services can work together to solve real-world data processing challenges. It also highlighted the importance of architectural design when building intelligent applications.

### 4. Greater Appreciation for Technology Communities

The presentations about AWS Community Day showed me that participating in technical communities is not only a way to learn new technologies but also an opportunity to build professional networks, exchange ideas, and continuously improve personal skills.
