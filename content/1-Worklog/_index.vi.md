Chương trình thực tập **AWS First Cloud AI Journey (FCAJ)** của sinh viên **Nguyễn Long Toàn** được thực hiện trong thời gian **8 tuần** với mục tiêu nghiên cứu, triển khai và hoàn thiện dự án **Fav Web Portal** trên nền tảng điện toán đám mây **Amazon Web Services (AWS)**.

Dự án tập trung xây dựng một hệ thống web đa phương tiện tích hợp tính năng **nhận diện khuôn mặt (Face Recognition)**, đồng thời triển khai các thành phần hệ thống lên AWS nhằm tìm hiểu quy trình xây dựng và vận hành một ứng dụng Web trên Cloud.

Trong quá trình thực hiện, tập trung vào việc tìm hiểu AWS, chuẩn bị môi trường phát triển, triển khai hệ thống lên Cloud, tích hợp các dịch vụ AWS và hoàn thiện tài liệu Workshop theo template FCAJ.
