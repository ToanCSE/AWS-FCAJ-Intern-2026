The **AWS First Cloud AI Journey (FCAJ)** internship program of **Nguyễn Long Toàn** is conducted over a period of **8 weeks** with the objective of researching, implementing, and completing the **Fav Web Portal** project on the **Amazon Web Services (AWS)** cloud platform.

The project focuses on developing a multimedia web system integrated with **Face Recognition** functionality while deploying system components on AWS to explore the process of building and operating a Web application on the Cloud.

Throughout the implementation process, the main activities include learning AWS services, preparing the development environment, deploying the system on the Cloud, integrating AWS services, and completing the Workshop documentation based on the FCAJ template.

### Weekly Progress Overview:

- **Week 1:** [Introduction to AWS and Development Environment](1.1-week1/)
- **Week 2:** [Architecture Design and Deployment Preparation](1.2-week2/)
- **Week 3:** [Deploying AWS EC2 and Amazon S3](1.3-week3/)
- **Week 4:** [Integrating Amazon RDS Database](1.4-week4/)
- **Week 5:** [Logging and Monitoring with Amazon CloudWatch](1.5-week5/)
- **Week 6:** [Performance Optimization and System Security](1.6-week6/)
- **Week 7:** [System Testing and Final Improvements](1.7-week7/)
- **Week 8:** [Workshop and Report Completion](1.8-week8/)
