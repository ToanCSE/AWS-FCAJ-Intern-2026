### Week 3 Objectives:
* Start deploying the **Fav Web Portal** system on the AWS Cloud environment.
* Learn and configure AWS services required for the application deployment process.
* Deploy the Backend experimentally and integrate data storage with AWS S3.

| Day | Tasks | Start Date | Completion Date |

### Week 3 Achievements:
* Understood the process of deploying a Backend application on AWS EC2.
* Successfully configured the application runtime environment on the Cloud.
* Successfully integrated AWS S3 to support data storage for the system.
* Completed the first deployment stage of the **Fav Web Portal** system on the AWS platform.
